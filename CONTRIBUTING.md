# Contributing to FreshPress

Thanks for your interest in FreshPress!

## Issues and ideas are welcome

Bug reports, questions and feature ideas are very welcome. Please open an issue in
this repository, or email support@indieops.co.

## Code contributions

We aren't accepting code contributions (pull requests) for now. This repository is a
generated copy of the FreshPress free edition: each release lands as a single commit
from the private development workspace, so pull requests can't be merged here
directly. If you've found a fix, describe it in an issue and we'll look at it.
